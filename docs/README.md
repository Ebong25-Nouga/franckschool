# Documentation FRANCK SCHOOL

| Dossier | Contenu |
|---|---|
| `references/` | Documents fournis par le propriétaire (document maître, documentation BD) |
| `base-de-donnees/` | Audit et modèle de données (sources Markdown modifiables) |
| `schemas/` | Code source des schémas Mermaid (`.mmd`) |
| `decisions/` | Journal des décisions |
| `pdf/` | Versions PDF générées |

Pour visualiser un schéma `.mmd` : le coller sur https://mermaid.live, ou l'ouvrir sur GitHub, qui affiche les blocs Mermaid des fichiers Markdown.

L'historique complet (date, auteur, motif de chaque changement) est conservé par Git.
